# Fafa Desktop Pet v0.1.0

Meet Fafa, a fluffy photo-based desktop companion for Windows (64-bit).

- Drag Fafa around the screen and click to pet her.
- Feed, play, and nap with three photo-based poses.
- Portable app: download and run, with no installation.

The build is unsigned, so Windows may show an unrecognized-app warning. Download only from this release page and verify the SHA-256 if needed:
